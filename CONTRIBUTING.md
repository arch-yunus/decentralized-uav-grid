# Katkda Bulunma (Contributing)

Decentralized UAV Grid (DUG) projesine ho geldiniz! Bu proje, merkeziyetsiz sr zekas teknolojilerini gelitirmeyi hedefleyen ak kaynak bir giriimdir. Katklarnz bizim iin deerlidir.

## Nasl Katkda Bulunabilirsiniz?

1.  **Hata Bildirimi:** Karlatnz hatalar GitHub Issues zerinden detayl bir ekilde bildirebilirsiniz.
2.  **Yeni zellik Talebi:** Projeye eklenmesini istediiniz zellikleri tartmaya amak iin bir issue oluturun.
3.  **Kod Gelitirme:** 
    *   Repoyu çatallayın (Fork).
    *   Yeni bir özellik dalı (feature branch) oluşturun: `git checkout -b ozellik/yeni-ozellik`.
    *   Değişikliklerinizi yapın ve test edin.
    *   Değişikliklerinizi commit edin: `git commit -m 'Yeni özellik eklendi'`.
    *   Dalı (branch) pushlayın: `git push origin ozellik/yeni-ozellik`.
    *   Bir Pull Request (PR) açın.

## Kod Standartlar

*   C++ iin ROS2 kodlama standartlarn takip edin.
*   Fonksiyon ve deiken isimlerini aklayc sein.
*   Yorum satrlarn mmkn olduunca İngilizce veya Türkçe (tutarlı bir şekilde) ekleyin.

## İletişim

Sorularınız veya iş birliği talepleriniz için GitHub üzerinden bizimle iletişime geçebilirsiniz.
